# EcoTrend

## Overview  
*EcoTrend* is a web portal that enables students to upload and track their project metrics aligned with Sustainable Development Goals (SDGs). Faculty members can view the performance scores of their respective students, while the admin can monitor all faculties and the overall student progress in one place.

## Features  
- *Student Dashboard:* Upload and monitor project performance against SDG goals.  
- *Faculty Access:* View project scores of students under their supervision.  
- *Admin Panel:* Track performance across all faculties and students.  
- *Centralized Metrics:* Unified view of SDG alignment and progress tracking.  

## Tech Stack  
### Frontend  
- *HTML* – Structure  
- *CSS* – Styling  
- *JavaScript* – Interactivity  

### Backend  
- *Node.js* – Server environment  

### Database  
- *MongoDB* – Data storage  

## Setup & Installation  
### Prerequisites  
- Node.js installed  
- MongoDB running locally or in the cloud

#### Start MongoDB  
Ensure your MongoDB instance is running.

#### Start the Server  
From the project root directory:
